# 转换csv内容，类Anki导入界面插件

这是一个用于转换CSV内容的插件，模仿Anki导入界面的功能。

## 功能介绍

- 将CSV文件内容转换为Anki可导入的格式
- 提供类似Anki导入界面的操作体验
- 支持字段映射和分隔符设置

## 使用方法

1. 将CSV文件内容粘贴到输入框
2. 设置分隔符（默认为逗号）
3. 映射字段到Anki卡片模板
4. 点击转换按钮生成Anki可导入的内容
